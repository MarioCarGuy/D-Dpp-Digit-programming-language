# D-Dpp-Digit-programming-language
a sequel to D/Digit programming language way shorter commands and faster to write!
---------------------------------------------------------------------------------------------------------------------------
First are typing letters:
1. Use this method example: a=01 b=02...
2. to type a capital letter type "_" before a number like this: _01
3. to type a space write "00"
4. here's an hello world example: "_08 05 12 12 15 00 23 15 18 12 04"
---------------------------------------------------------------------------------------------------------------------------
Second are typing variables:
1. type a question mark and a number up to 99
2. but you can write bigger numbers like this: "?99 ?99" that will type 9999
---------------------------------------------------------------------------------------------------------------------------
Third is typing marks like ".!?":
1. Type a dot and a number 60 and up (im not sure there are all marks so yah) example: ".60" that types a "." (im not sure)
---------------------------------------------------------------------------------------------------------------------------
